# あけトレ（明けトレ）｜ 夜勤明けでも続く筋トレメモ

不規則勤務（日勤・夜勤・明け・休みなど）がある人向けの、通信ゼロの筋トレ記録アプリです。

## 使い方

`index.html` をブラウザで開くだけです。インストールやビルドは不要です。
スマホでは共有メニューから「ホーム画面に追加」すると、全画面・オフラインで起動できます。

## 特徴

- 完全オフライン・通信ゼロ（外部サーバーへの通信は一切行いません）
- 記録データはすべて端末内（localStorage）に保存され、外部には送信されません
- 器具カテゴリー別（バーベル・ダンベル等）の種目記録、有酸素、体組成、コンディション記録
- シフト（日勤/夜勤/明け/休み）ごとのパフォーマンス傾向を可視化
- 自己ベスト（推定1RM・実測MAX重量）を部位別に一覧表示
- 日本語・English・中文・Español・Français・Deutsch・Italiano に対応

## このリポジトリについて

本アプリは元々オフライン専用の販売アプリとして開発したものを、ソースコードを公開できる形に調整して公開しています。
そのため、有料プラン解除用のコード判定ロジックはこの公開版には含まれておらず、常に無料プランとして動作します。
